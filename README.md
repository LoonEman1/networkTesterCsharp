# UDP Network Tester

## Описание проекта

Консольное приложение для тестирования передачи данных по сети с использованием UDP.

Программа работает в двух режимах:

- UDP Server — принимает пакеты и рассчитывает параметры передачи;
- UDP Client — генерирует и отправляет UDP пакеты с заданными параметрами.

Приложение позволяет измерять:
- скорость передачи и приема данных;
- количество отправленных и принятых пакетов;
- количество потерянных пакетов;
- jitter (изменение времени между пакетами).

## Требования

- .NET 8
- Windows / Linux

## Запуск

После запуска необходимо выбрать режим:

```
сервер
```

или

```
клиент
```

## Сервер

После выбора режима необходимо указать порт прослушивания.

Пример:

```
Порт: 5000
```

Сервер начинает принимать UDP пакеты и выводить статистику работы.

## Клиент

Необходимо указать:

- IP адрес сервера;
- порт сервера;
- скорость генерации пакетов;
- размер пакета.

Пример:

```
IP сервера: 127.0.0.1
Порт: 5000
Скорость: 100
Размер пакета: 1024
```

После запуска клиент начинает отправку UDP пакетов.

## Завершение работы

Для остановки приложения необходимо нажать:

```
q + Enter
```

## Логи

Во время работы создается папка:

```
Logs/
```

В папку записываются CSV файлы:

```
client.csv
server.csv
```


## Формат пакета

UDP пакет содержит:

- Signature — идентификатор пакета;
- Packet Size — размер пакета;
- Sequence Number — номер пакета;
- Timestamp — время генерации;
- Payload — данные заполнителя.
